## Risks & open questions
- **Ortam (R-13) — doctor verdict:** check.conf'ta henüz adım yok, doctor'ın profil hükmü yok.
  Bu makinede: **fast çalışabilir** (Flutter 3.41.2 / Dart 3.11.0). **full çalışamaz**:
  `flutter doctor` → "No Java Development Kit (JDK) found" → `apk` adımı kırmızı olur.
  **Önerim:** JDK 17'yi kur (`winget install Microsoft.OpenJDK.17`, ardından
  `flutter config --jdk-dir <yol>`); `requires apk` JDK'yı da denetler. Gerekçe: tam profilin yerelde
  koşması, Android derleme hatalarını CI turunu beklemeden yakalar. Alternatif: `apk` yalnızca CI'da
  (yerel full = fast + CI) — daha az kurulum, daha yavaş geri bildirim.
- **R2 — sqlite3 yerel kütüphanesi (host testleri):** drift'in `NativeDatabase`'i Windows/Linux test
  makinesinde sqlite3 kütüphanesine ihtiyaç duyar; makinede `sqlite3.dll` yok. **Önerim:** sqlite'ı
  derleme kancasıyla kendisi paketleyen `sqlite3` sürümünü kullanmak (drift'in güncel sürümleri);
  olmazsa `requires test` satırıyla gereksinimi açık etmek ve sana sormak.
- **R3 — minSdk 23:** Flutter 3.41'in desteklediği alt sınır 23'ün üstündeyse ADR 0001 ile çelişir.
  **Önerim:** adım 1'de `flutter.minSdkVersion` okunur; 23'ün üstündeyse BUILD durur ve sana
  sorulur (R-10) — sessizce yükseltilmez.
- **R4 — flutter create mevcut dosyaları ezebilir** (README, .gitignore). Önerim: scratch dizinde
  oluşturup seçerek kopyalamak (adım 1).
- **R5 — gen-l10n çıktı yeri:** yeni Flutter'da sentetik paket yok; üretilen dosyalar `lib/l10n/`
  altına yazılır ve commit edilir; `codegen` adımı bunların güncelliğini de denetler.
- **R6 — Gradle/Kotlin daemon residue:** `android/gradle.properties` (`org.gradle.daemon=false`,
  `kotlin.compiler.execution.strategy=in-process`) + `GRADLE_OPTS`; residue testi kanıtlar.
- **R7 — CI süresi:** APK derlemesi CI'a ~3–5 dk ekler. Önerim: kabul; tam profil CI'da tek kanıt.
- **R8 — Yeni bağımlılıklar (insan onayı, `docs/security.md`):** `flutter_riverpod`, `drift`,
  `drift_flutter` (cihazda DB açılışı; `path_provider`'ı getirir), `intl`, `flutter_localizations` (SDK);
  dev: `drift_dev`, `build_runner`, `flutter_lints`. Hepsi MIT/BSD, aktif bakımda. Sürümler
  `flutter pub add` ile güncel stable çözülür, `pubspec.lock` sabitler. **Plan onayı bu listeyi onaylar.**
